# Slidev Creator

独自性のある高品質なSlidevプレゼンテーションを作成するプラグイン。

## 特徴

- 大胆な美的方向性でプレゼンテーションを作成
- 汎用的なAI生成デザインを避ける
- タイポグラフィ・カラー・モーションに細心の注意
- Slidevのマークダウン形式で出力

## コマンド

| コマンド | 説明 |
|----------|------|
| `/create-slide` | Slidevプレゼンテーションを作成 |

## 使用例

```
/create-slide Claude Codeの紹介プレゼンを作成して
```

## デザイン方針

frontend-designスキルのガイドラインを参考に、以下を重視:

- **タイポグラフィ**: 個性的なフォント選び（Inter、Robotoは避ける）
- **カラー**: 支配的な色と鋭いアクセントの組み合わせ
- **モーション**: 高インパクトな瞬間でのアニメーション
- **空間構成**: 予想外のレイアウト、非対称性
- **背景**: グラデーションメッシュ、テクスチャなど雰囲気づくり

## インストール

```bash
/plugin install slidev-creator@masayan-uni-plugins
```
