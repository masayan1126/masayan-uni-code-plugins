# ユーザー入力フォーム

スクリプト生成に必要な情報をヒアリングする。

## 必須情報

### 1. スクリプトの目的
**質問**: このスクリプトで何を実現したいですか？
- 例: ファイルのバックアップ、ログの収集、デプロイ自動化など

### 2. 出力ファイルパス
**質問**: スクリプトをどこに保存しますか？
- 例: ./scripts/backup.sh

## オプション情報

### 3. フラグオプション（-f形式）
**質問**: ON/OFFで切り替えるオプションはありますか？
- 例: --dry-run（実際には実行しない）、--force（確認なしで実行）

### 4. 名前付きパラメータ（-p value形式）
**質問**: 値を指定するオプションはありますか？
- 例: --output-dir /path/to/dir、--config config.json

### 5. 位置引数
**質問**: オプション以外の引数（ファイル名など）は必要ですか？
- 例: backup.sh file1.txt file2.txt

### 6. クリーンアップ処理
**質問**: スクリプト終了時に片付けが必要なものはありますか？
- 例: 一時ファイルの削除、ロックファイルの解除

### 7. 色付き出力
**質問**: ログメッセージに色を付けますか？
- デフォルト: はい（--no-colorで無効化可能）

## 出力形式

収集した情報を元に、以下を生成：
1. 完全なBashスクリプト
2. 使用例（コメントまたは別途説明）
