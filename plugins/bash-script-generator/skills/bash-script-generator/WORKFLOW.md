# ワークフロー

## 1. 要件ヒアリング

FORMS.mdのフォームを使用してユーザーから以下を収集：
- スクリプトの目的・概要
- 必要なオプション（フラグ、名前付きパラメータ）
- 位置引数の有無
- クリーンアップ処理の必要性
- 出力ファイルパス

## 2. スクリプト生成

TEMPLATE.mdのテンプレートをベースに：
1. usage()関数を更新（スクリプト説明、オプション一覧）
2. parse_params()を更新（必要なオプションを追加）
3. cleanup()を更新（必要なクリーンアップ処理を追加）
4. メインロジックを実装

## 3. 出力

指定されたパスにスクリプトを出力し、実行権限を付与。
